# Provenienza e limiti

Il nucleo deriva dal Magias UI Protocol v0.2, revisione privata. Le lenti culturali sono interpretazioni contemporanee, non regole UI tradizionali certificate. La lettura integrale della fonte primaria di Kuki resta aperta.

- [WCAG 2.2](https://www.w3.org/TR/WCAG22/): fonte normativa per applicabilità, definizioni ed eccezioni dei criteri.
- [Japanese Aesthetics, Stanford Encyclopedia of Philosophy](https://plato.stanford.edu/entries/japanese-aesthetics/): contesto culturale secondario.
- [UCLA, Ma](https://forms.international.ucla.edu/japan/event/16872): riferimento spaziale e temporale.

Queste fonti non dimostrano efficacia commerciale, conformità di un sito o qualità della skill.
