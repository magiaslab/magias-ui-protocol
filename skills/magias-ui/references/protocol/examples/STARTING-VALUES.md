# Valori di partenza facoltativi

v0.2 · esempi, esclusi dal gate.

Per una pagina commerciale/editoriale si può esplorare spazio 4/8/12/16/24/32/48/64 px, corpo 16–20 px e circa 45–75 caratteri per riga desktop. Feedback locali 120–180 ms e pannelli 180–260 ms sono riferimenti esplorativi, non standard.

Per una UI operativa può servire densità maggiore, scala compatta e più segnali simultanei. Per una narrazione può servire una sequenza più lunga con accesso diretto. Leggere contenuti, brand e componenti prima di usare questi numeri. Valori differenti non sono FAIL.
